AJ STORES — ONLINE PRODUCT MANAGEMENT

PRODUCT ADD / EDIT / DELETE
1. Online hosting করার পর GitHub-এ products.json file খুলবে।
2. Edit (pencil icon) চাপবে।
3. নিচের format-এ product যোগ করবে:
[
  {
    "store": "AJ Trendy Hub",
    "name": "Black Backpack",
    "price": 650,
    "description": "Stylish backpack",
    "image": "YOUR_IMAGE_URL",
    "status": "ON"
  }
]
4. AJ Kidz Zone product হলে store হবে "AJ Kidz Zone".
5. Product দেখাতে status = "ON".
6. Product hide করতে status = "OFF".
7. Product delete করতে পুরো product block delete করবে।
8. Price শুধু price-এর number বদলালেই হবে।

IMAGE
Google Drive link সরাসরি না দিয়ে public image URL ব্যবহার করা সবচেয়ে সহজ।
GitHub-এ image upload করে সেই image URL-ও ব্যবহার করা যাবে।

ONLINE HOSTING — FREE GITHUB PAGES
1. GitHub.com-এ account খুলে Sign in করো।
2. New repository → নাম: aj-stores → Public → Create repository.
3. এই ZIP extract করে সব files repository-তে upload করো।
4. Settings → Pages → Deploy from branch → main → /(root) → Save.
5. কিছুক্ষণ পর GitHub একটি website link দেবে।
6. সেই link-এ website চলবে।
7. এরপর products.json GitHub থেকেই Edit করে product change করা যাবে।

IMPORTANT
- Google Sheet-এর Orders system একই থাকবে।
- Orders tab-এ order যাবে।
- Products tab আর প্রয়োজন হবে না।
- Local file (file://) দিয়ে products.json load নাও হতে পারে; online GitHub Pages-এ ঠিকমতো load হবে।
